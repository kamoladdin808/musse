# Musse — лендинг кондитерской

Статический сайт без зависимостей: 2 страницы, чистый HTML / CSS / JS.
Дизайн-направление: **Artisanal Red** — тёплый кремовый фон + глубокий бордово-терракотовый акцент.

## Запуск

Открыть `index.html` в браузере — или поднять локальный сервер:

```
npx serve .
```

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | Главная: hero, акции, о нас, фото заведения, карта, футер |
| `menu.html` | Меню: табы категорий + каталог с фильтрацией |
| `css/style.css` | Дизайн-система (палитра, типографика, анимации, текстуры) |
| `js/main.js` | Хедер, анимации, параллакс, каталог `PRODUCTS`, Telegram-ссылки |
| `robots.txt`, `sitemap.xml` | SEO |

## Фотографии

Все визуалы сейчас — **SVG-заглушки в фирменной палитре**. После съёмки заменить:

- **Hero** — заменить `<div class="hero-art">…</div>` на `<img>` (WebP, 1920px+, светлый фон).
  Лучшая композиция: десерт внизу/справа, чтобы текст сверху не перекрывал.
- **Акции** — содержимое `.promo-media`.
- **Фото заведения** — содержимое `.venue-photo` (атрибут `data-parallax` оставить на `<img>`).
- **Карточки товаров** — в `js/main.js` поле `art` заменить на `photo: "img/products/….webp"`
  и в `renderCard` подставлять `<img loading="lazy" alt="...">` вместо `productArt(p)`.

## Наличие товаров

Управляется вручную: флаг `available: true/false` у позиций в массиве `PRODUCTS` (`js/main.js`).
В Фазе 2 массив заменяется загрузкой из админ-панели — структура данных совместима
(id, категория, название, описание, цена, наличие).
